# Signal Plot Mono

`signal-plot-mono.woff2` is derived from [DejaVu Fonts 2.37](https://dejavu-fonts.github.io/).
It contains printable ASCII from DejaVu Sans Mono and U+2800–U+28FF from DejaVu
Sans. Braille glyphs are scaled horizontally to match the monospace character
width, which keeps the plots and their labels aligned without depending on
system font coverage. The derived family is named Signal Plot Mono.

The font is self-hosted and requires no third-party requests. See `LICENSE.txt`
for the original license.
